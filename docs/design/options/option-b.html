Your agent got worse. The gate stays down.

casegate runs labelled cases against your LLM system, scores the answer and the tool trajectory, compares the run with a baseline and fails the build on regression.

$ uv add casegate

Seven scorers. One verdict.

A case passes only when every scorer passes. Errors are counted on their own line, never as failures.

Trajectory, not only text

Score the tool calls in order, as a subsequence or as a set, with matchers for each argument.

A judge you can check

Calibrate the LLM judge against your own labels. casegate reports agreement and Cohen's kappa.

Variance, not luck

Repeat each case N times. The gate tolerance comes from the measured spread.

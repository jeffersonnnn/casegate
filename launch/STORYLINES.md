# Storylines (M5 launch videos)

The one claim: **casegate blocks the pull request that makes your agent worse.**
The one thing to remember: "my unit tests passed, but the gate caught the agent getting worse."
The spine: one real pull request (PR #1 of `jeffersonnnn/casegate`, FACTS §9). One real change travels through it: `get_order` returns money as integer cents.

Three directions were written. Two were cut. The milestone ran with no stops, so the recommendation was built.

## A. "Lab instrument" (BUILT)

- Device: the bug itself, then a number lands. Form: one home stage (the DESIGN §1 dark instrument with hairline grid and corner telemetry); the 3D barrier arm is the carrier the eye follows from the gate to the end card.
- What the viewer sees: a harmless diff, 468 green unit tests, then the case tick row grows and two ticks turn red. The arm lifts a little, drops and the sticky comment says BLOCKED. A fix push re-runs the ticks, the arm lifts, and the same comment says PASSED.
- First two seconds: the real `store.py` diff already on screen (frame 0), its five `+` lines wiping in, the title "A small refactor."
- Beats: diff → tests pass → "The agent got worse." → tick row runs, 2 flips → arm drop + BLOCKED comment → fix push → arm lift + PASSED → claim → mark + `uv add casegate`.
- Look: DESIGN tokens only, IBM Plex, one signal colour at a time (red, then green).
- Sound: a dark 124 BPM synth bed, low-passed while the regression builds; it cuts out for one bar on the thud and opens to full band on PASSED.
- Why this one: a stranger follows it with no words, and every frame is a real artefact of the demo PR.

## B. "The PR page" (cut)

- Device: one object across apps. Form: one continuous take down a GitHub pull request page: commits, checks, the bot comment, then the edit.
- Cut because it rebuilds GitHub chrome around the comment, which reads as a mock-up, and the 3D mark has no home in it.

## C. "Type carries the argument" (cut, the bold one)

- Device: type carries the argument. Form: cut on the beat; giant numbers `0.973`, `0.853`, `−0.120`, `limit 0.08` slam on the bar lines, then the arm.
- Cut because numbers alone do not show what the gate does; the comment and the tick row do.

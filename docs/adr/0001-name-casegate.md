# 0001 Name the project casegate

Status: accepted (2026-11-11)

## Context
The brief named the project `evalgate`. On 2026-11-11 the PyPI names `evalgate` (0.3.0), `evalgate-ai` (0.6.0) and `evalgate-cli` (0.2.0) were taken, and five GitHub users had repos named `evalgate`. `casegate` was free on PyPI and GitHub.

## Decision
Use `casegate` for the GitHub repo, the PyPI distribution, the import package and the CLI command.

## Why
One name everywhere is easy to explain and easy to find. A search for the name finds this project, not three others.

## Consequences
Every doc, workflow and example uses `casegate`. The brief's `evalgate` name appears only in this ADR. Re-check that the PyPI name is still free before the first publish (M3).
